# FPGA-Based Implementation of an 8-bit SAR ADC using Verilog HDL

## Overview
This project demonstrates the implementation of the digital Successive Approximation Register (SAR) Controller for an 8-bit Analog-to-Digital Converter (ADC) using Verilog HDL on a Xilinx Basys-3 FPGA.

Unlike a complete SAR ADC implemented entirely in hardware, this project focuses on the digital control logic while integrating external analog components.

The hardware consists of

- Basys-3 FPGA
- External DAC IC
- Comparator Circuit
- Function Generator
- Breadboard Interface

The FPGA performs the SAR algorithm while the DAC and comparator form the analog feedback loop.

## Working Principle
The analog voltage generated by the function generator is applied to one input of the comparator.

The SAR Controller running on the FPGA
- Sets the MSB
- Sends the digital code to the DAC
- DAC converts it into an analog voltage
- Comparator compares Vin with VDAC
- Comparator sends 1-bit feedback
- FPGA keeps or clears the bit
- Process repeats until the LSB
Finally, the FPGA outputs the complete 8-bit digital representation of the analog input.
