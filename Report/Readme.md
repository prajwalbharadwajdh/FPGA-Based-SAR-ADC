# Project Report

This folder contains the complete mini project report titled **"FPGA-Based Implementation of SAR ADC Using Verilog HDL."** The report documents the design and implementation of an **8-bit Successive Approximation Register (SAR) Controller** on a Xilinx Basys-3 FPGA.

The report covers the project's objectives, literature survey, system architecture, methodology, Verilog implementation, simulation, FPGA synthesis, hardware testing, and performance evaluation. It also explains the integration of the FPGA-based SAR controller with an external DAC IC and a custom-built comparator circuit to realize a complete mixed-signal SAR ADC.

Additionally, the report includes simulation results, FPGA resource utilization, hardware validation, conclusions, future enhancements, references, and the Verilog source code used for implementing the SAR controller.
